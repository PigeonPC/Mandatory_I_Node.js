1.1 Variabler og Datatyper

Variabler

Vi bruger tre måder at deklarere værdier i JavaScript: const, let og var.

const: Kan ikke tildeles en ny værdi efter deklarationen.

let: Kan ændres og tildeles en ny værdi.

var: Brug ikke! Gammel. Er ikke block-scoped.

RULE: Brug altid const. Ellers brug let. Aldrig var.

const myFavoriteNumber = 7;

let age = 25;
age = 26;

Datatypes

String: Tekst. Skrives i citationstegn. Primitiv.

Boolean: Kan have værdien true eller false. Primitiv.

Number: Tal. Både hele og decimaltal. Primitiv.

BigInt: Bruges til meget store tal som Number ikke kan vise præcist. Primitiv.

null: Betyder at en værdi bevidst er sat som ingenting. Primitiv.

undefined: En variabel der ikke har fået tildelt en værdi. Primitiv.

Object: Kan samle flere værdier i ét objekt. Indeholder typisk key-value pairs.

({ name: "Olga", age: 27 })

Symbol: Kan lave unikke værdier. Primitiv.

1.2 Objects og Arrays

Objects

Objekter består af key-value pairs.

const person = {
    // key-value pair
    name: "Adam"
};

// Tilføjer en ny key-value pair til objektet
person.age = 30;

// Slet navnet under objektet person
delete person.name;

Selvom person er deklareret med const, kan vi stadig godt ændre i indholdet. 

console.log(person); // { age: 30 }

Arrays

Et array er også en type af objekt der kan gemme værdier i en liste. Arrays starter ved index 0. 

const things = ["mouse", "car", "cat"];

console.log(things[0]); // "mouse"
console.log(things[1]); // "car"

Array methods

push(): Tilføjer et eller flere elementer til slutningen af et array.

pop(): Fjerner det sidste element i et array.

length: Viser antallet af elementer i et array.

indexOf(): Finder index for en bestemt værdi. Returnerer -1 hvis værdien ikke findes.

splice(): Kan tilføje, fjerne eller erstatte elementer i et array.

Spread syntax (...): Kan bruges til at kopiere elementer fra et array til et nyt array.

push(), pop() og length

const things = ["mouse"];

things.push("car"); // Tilføjer "car"
things.pop();       // Fjerner "car"

console.log(things);        // ["mouse"]
console.log(things.length); // 1

indexOf()

const numbers = [10, 20, 30];

console.log(numbers.indexOf(20)); // 1
console.log(numbers.indexOf(50)); // -1

splice()

const diet = ["tomato", "cucumber", "rocket"];

diet.splice(2, 0, "hamburger", "pizza");

console.log(diet);
// ["tomato", "cucumber", "hamburger", "pizza", "rocket"]

splice(startIndex, deleteCount, items) bestemmer hvor vi starter, hvor mange elementer der skal fjernes og hvad der eventuelt skal indsættes.

Spread syntax (...)

const diet = ["tomato", "cucumber", "rocket"];
const dinnerTray = [...diet];

Opretter et kopieret array med samme elementer.

Reference Types

Objects og arrays er ikke primitive typer, men reference types. Dvs. at hvis vi tildeler et objekt til en anden variabel, vil de begge referere til det samme objekt. Så hvis man ændrer i den ene, vil det også kunne ses gennem den anden. 

const fruits = ["apple", "banana"];
const otherFruits = fruits;

otherFruits.push("orange");

console.log(fruits);
// ["apple", "banana", "orange"]

Ændringer i otherFruits påvirker derfor også fruits.

1.3 Strings og Template Literals

Strings kan skrives på flere måder, fx med dobbelte eller enkelte citationstegn. 

const greetingOne = "Hej, godt at se dig igen";

Man kan godt have dobbelte citationstegn i en string hvis man har brugt enkelte yderst. 

const greetingTwo = 'Hej, godt at se dig "ven"';

Man kan også bruge backticks (`), som kaldes template literals. Med backticks kan man både bruge dobbelte og enkelte citationstegn. De kan også bruges til multiline strings og til at indsætte JavaScript-variabler med ${}. 

const greetingThree = `Hej med 'dig', "${person.name}"`;

String methods

Vi kan bruge forskellige metoder til at arbejde med tekst.

replace() kan erstatte dele af en string.

const fact = "You are learning javascript!";

const result = fact.replace("javascript", "Javascript");

console.log(result); // You are learning Javascript!

Vi kan også tage fat i et specifikt tegn i en string ved at bruge index. Starter ved 0 ligesom arrays. 

const letters = "abc";

console.log(letters[2]); // c

1.4 Scope

Scope bestemmer hvor en variabel kan tilgås fra. Altså hvor langt dens reach er i koden.

Global scope: En variabel der er deklareret uden for funktioner og blokke.

Function scope: Variablen kan tilgås i den funktion den er deklareret i.

Block scope: Variablen kan tilgås inde i den blok {} den er deklareret i.

var er ikke block-scoped, men let og const er det!

{
    var someValue = 123;

    {
        var someValue = 456;
    }

    console.log(someValue); // 456
}

Her er someValue 456. Det er fordi var ikke er block-scoped og derfor kan ændres uden for den blok den er deklareret i.

let er anderledes.

{
    let someOtherValue = true;

    {
        let someOtherValue = false;
    }

    console.log(someOtherValue); // true
}

RULE: Brug let frem for var! Vi vil gerne undgå at variabler kan påvirke hinanden ved en fejl.

1.5 Strict Mode

Strict mode gør at JavaScript fanger visse fejl, som når man prøver at bruge en udeklareret variabel. 

"use strict";

totalGlobalVariable = "Never EVER do this";

Det her vil give en fejl fordi variablen ikke er deklareret. Dvs. man skal tilføje const eller let.

1.6 Type Coercion

Type coercion betyder at JavaScript konverterer en datatype til en anden. 

console.log("5" + 2); // "52", string
console.log("5" - 2); // 3, Number

Ved + bliver tallet lavet til en string, mens - får det til at blive et tal. Det er ikke så fedt.

For at undgå problemer kan det fx skrives sådan:

const number = Number("5");

console.log(number + 2); // 7

RULE: Brug komma i console.log() frem for + når vi vil printe flere værdier. + kan nemlig medføre type coercion.

Konvertering af datatyper

Vi kan konvertere strings til numbers med flere metoder:

Number(): Konverterer en string til et tal. Returnerer NaN hvis den ikke kan konverteres.

parseInt(): Konverterer starten af en string til et tal.

parseFloat(): Konverterer starten af en string til et decimaltal.

toFixed(): Kan formatere et tal med et specifikt antal decimaler. Returnerer en string.

console.log(Number("2025"));      // 2025
console.log(parseInt("1234abc")); // 1234
console.log(parseFloat("1.10"));  // 1.1

const number = 3.4;
console.log(number.toFixed(2));   // "3.40"

=== vs ==

Vi vil helst bruge === til sammenligning da den sammenligner uden type coercion, som == gør. 

5 == "5";  // true
5 === "5"; // false

Her bliver == true fordi den konverterer værdierne til samme datatype.

1.7 Hoisting

Hoisting betyder at man i JavaScript kan kalde en function declaration før den står i koden, fordi JavaScript håndterer deklarationer før koden køres. 

getRandomInt(5, 10);

function getRandomInt(min, max) {
    return Math.floor(Math.random() * (max - min + 1) + min);
}

Her kaldes funktionen før den er deklareret. let og const kan ikke bruges før deres deklaration.

1.8 Truthy og Falsy

I JavaScript kan værdier fortolkes som true eller false selv hvis de ikke er booleans.

Falsy: false, 0, "", null, undefined, NaN, 0n.

Truthy: De fleste andre værdier, fx "hello", 42, [] og {}.

Fx bliver else kørt her fordi en tom string gælder som falsy. 

const name = "";

if (name) {
    console.log("Has a name");
} else {
    console.log("No name");
}

1.9 Logical Operators (||, ??, &&)

|| (OR): Returnerer den første truthy værdi, ellers den sidste værdi.

?? (Nullish Coalescing): Returnerer værdien til højre hvis værdien til venstre er null eller undefined.

&& (AND): Returnerer den første falsy værdi, ellers den sidste værdi.

const count = 0;

console.log(count || 10); // 10
console.log(count ?? 10); // 0

VIGTIGT: || reagerer også på fx 0 og "", men ?? reagerer kun på null og undefined.

1.10 Increment og Decrement (++, --)

Man bruger ++ eller -- til at tilføje eller fjerne 1 fra en variabel. 

let counter = 0;

counter++; // counter = 1
counter--; // counter = 0

Der er forskel på om operatoren står før eller efter variablen. 

let number = 5;

console.log(number++); // 5
console.log(number);   // 6

console.log(++number); // 7

number++ returnerer den gamle værdi og øger variablen bagefter.

++number øger først variablen og returnerer den nye værdi.
