6.1 REST API

Hvad er et REST API?

Et REST API er en måde hvor client og server kan kommunikere med hinanden gennem HTTP.

Vi bruger endpoints til at arbejde med resources, fx hente, oprette, ændre eller slette dyr i vores Animals API.

REST-konventioner

I undervisningen følger vi tre REST-konventioner:

  1. HTTP Methods: Brug den rigtige HTTP-metode. Fx GET til at hente data og POST til at oprette data.
  2. Ordering: Brug den korrekte rækkefølge af HTTP-metoder: GET, POST, PUT, PATCH, DELETE.
  3. Naming: Brug navngivning i flertal der passer til samlingerne i systemet. Fx GET /animals.

REST API Design

Eksempel på endpoints til et Animals API: 

GET     /api/animals
GET     /api/animals/:id
POST    /api/animals
PUT     /api/animals/:id
PATCH   /api/animals/:id
DELETE  /api/animals/:id

6.2 HTTP Methods & CRUD

Hvad er CRUD?

Create, Read, Update, Delete. Det er de fire grundlæggende handlinger som vi kan gøre på data.

CRUD HTTP Method Handling
Create POST Opretter data
Read GET Henter data
Update PUT / PATCH Opdaterer data
Delete DELETE Sletter data

HTTP Methods

GET: Henter data fra serveren.

POST: Opretter en ny resource.

PUT: Erstatter en hel eksisterende resource.

PATCH: Opdaterer dele af en eksisterende resource.

DELETE: Sletter en resource.

6.3 HTTP Status Codes

Statuskoder

En HTTP status code fortæller klienten hvordan en request er gået. Om den lykkedes eller om der skete en fejl.

Family Meaning Examples
1xx Informational 100 Continue
2xx Success 200 OK, 201 Created, 204 No Content
3xx Redirection 301 Moved Permanently, 302 Found, 304 Not Modified
4xx Client Error 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found
5xx Server Error 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable

Typiske statuskoder

200 OK: Requesten lykkedes.

201 Created: En ny resource er oprettet.

204 No Content: Requesten lykkedes, men der sendes ikke noget indhold tilbage.

400 Bad Request: Serveren kan ikke behandle requesten pga. en fejl i den.

404 Not Found: Den ønskede resource findes ikke.

500 Internal Server Error: Der er sket en fejl på serveren.

Statuskoder i Express

app.get("/api/animals/:id", (req, res) => {
    const animal = animals.find(
        (animal) => animal.id === Number(req.params.id)
    );

    if (!animal) {
        return res.status(404).send({ error: "Animal not found" });
    }

    res.send({ data: animal });
});

Returnerer 404 hvis animal ikke findes. Ellers returnerer den 200 OK.
