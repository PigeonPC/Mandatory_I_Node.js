8.1 Static Files

Hvad er Static Files?

Filer som serveren sender direkte til clienten uden at ændre indholdet. Fx HTML, CSS, JavaScript og billeder.

express.static() og public-mappen

Vi bruger express.static() til at gøre statiske filer tilgængelige for browseren. 

import express from "express";

const app = express();

app.use(express.static("public"));

Gør filerne i public-mappen tilgængelige. Vi lægger filer til browseren i /public.

Det gør det nemmere at kontrollere hvilke filer der kan hentes af browseren.

8.2 Client vs. Server Files

Forskellen på Client og Server Files

Client files: Filer som sendes til browseren. Fx HTML, CSS, JavaScript og billeder. /public.

Server files: Filer som bruges på serveren. Fx app.js og backend-kode.

Hvorfor skal vi ikke serve alle filer?

Det er vigtigt for sikkerheden så clienten ikke har adgang til alle serverfiler. Følsomme oplysninger skal ikke deles med klienten.

8.3 Semantic HTML

Hvad er Semantic HTML?

Semantic HTML betyder at vi bruger HTML-tags som beskriver hvad indholdet på siden er.

Fx bruger vi <nav> til navigation i stedet for bare at bruge <div> til det hele.

Det gør koden nemmere at læse og forstå intuitivt.

nav, main og footer

<nav>: Indeholder navigation og links til andre sider.

<main>: Indeholder sidens vigtigste indhold.

<footer>: Indeholder typisk information nederst på siden. 

<body>
    <nav>
        <a href="/">Home</a>
        <a href="/about">About</a>
    </nav>

    <main>
        <h1>Planter</h1>
        <p>Welcome to Planter!</p>
    </main>

    <footer>
        <p>© 2026</p>
    </footer>
</body>

8.4 Frontend Structure

Mappestruktur

Vi opdeler vores frontend i forskellige mapper. Det gør det nemmere at holde overblik.

assets: Filer som bruges flere steder på hjemmesiden.

pages: De forskellige sider. Kan have deres egen HTML, CSS og JavaScript.

components: Dele af hjemmesiden som skal genbruges. Fx header, navigation og footer.

8.5 CSS Footer

Footer i bunden af siden

Vi vil gerne have at footeren ligger nederst på siden uanset mængden af indhold. Det kan vi gøre med Flexbox.

HTML

<body>
    <nav>Navigation</nav>
    <main>Page content</main>
    <footer>Footer</footer>
</body>

CSS

body {
    min-height: 100vh;
    display: flex;
    flex-direction: column;
}

main {
    flex: 1;
}

min-height: 100vh: Gør at body mindst fylder hele skærmens højde.

display: flex: Bruger Flexbox til at placere elementerne.

flex-direction: column: Placerer elementerne lodret.

flex: 1: Får main til at fylde den ledige plads så footeren skubbes ned i bunden.

Det betyder at footeren bliver nederst på siden, men stadig flytter sig længere ned hvis indholdet fylder mere end skærmens højde.
