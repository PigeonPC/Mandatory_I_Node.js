4.1 Modules

Hvad er et Module?

Et module er en JavaScript-fil der kan indeholde funktioner, variabler og objekter som vi kan eksportere og bruge i andre filer.

Det gør det nemmere at opdele vores kode i flere filer i stedet for at have alt i én stor fil.

4.2 CommonJS

require() og module.exports

CommonJS er et modulsystem i Node.js. Vi bruger module.exports til at eksportere og require() til at importere.

Herunder eksporterer vi fruits fra fruitsUtilCommonJS.js, så vi kan importere det i app.js.

fruitsUtilCommonJS.js

const fruits = ["apple", "banana", "orange"];

module.exports = fruits;

app.js

const fruits = require("./fruitsUtilCommonJS.js");

console.log(fruits);

4.3 ES Modules

import og export

ES Modules er et modulsystem i JavaScript. Vi bruger export til at eksportere fra en fil og import til at importere i en anden fil.

fruitsUtilESModule.js

export const fruits = ["apple", "banana", "orange"];

app.js

import { fruits } from "./fruitsUtilESModule.js";

console.log(fruits);

For at bruge ES Modules i vores Node.js-projekt kan vi tilføje dette til package.json: 

{
    "type": "module"
}

4.4 Modules i Frontend

type="module"

Vi kan også bruge ES Modules i browseren.

I HTML skal vi skrive type="module" på vores script: 

<script type="module" src="./app.js"></script>

Så kan vi bruge import og export mellem vores JavaScript-filer i frontend.

4.5 CommonJS vs. ES Modules

CommonJS

require(): Importerer et module.

module.exports: Eksporterer fra et module.

Ældre modulsystem i Node.js.

Bruges stadig i mange Node.js-projekter.

ES Modules

import: Importerer fra et module.

export: Eksporterer fra et module.

Standardiseret JavaScript-modulsystem.

Kan bruges i både frontend og Node.js.

Gør det muligt at genbruge samme syntax i frontend og backend.
