7.1 HTTP

Hvad er HTTP?

HTTP står for Hypertext Transfer Protocol. Det er en protokol som client og server bruger til at kommunikere med hinanden.

HTTP Request og Response

En HTTP request er en forespørgsel som clienten sender til serveren. Serveren behandler requesten og sender en HTTP response tilbage.

Request: Indeholder bl.a. en HTTP method, URL, headers og eventuelt en body.

Response: Indeholder en statuskode, headers og eventuelt en body med data.

Fx hvis vi skriver http://localhost:8080/api/animals i browseren, sender browseren en GET request til serveren. Serveren kan derefter sende vores animals-array tilbage som JSON.

7.2 URL Anatomy

Opbygning af en URL

En URL (Uniform Resource Locator) er en resources adresse. Den består af forskellige dele. 

https://www.example.com:8080/animals/5?type=cat#details

Protocol: https:// - Bestemmer hvilken protokol der bruges.

Subdomain: www - Et underdomæne.

Domain: example.com - Domænenavnet.

Port: 8080 - Den port serveren bruger.

Path: /animals/5 - Stien til den resource vi vil tilgå.

Query string: ?type=cat - Ekstra information sendt med URL'en.

Fragment: #details - Henviser til en bestemt del af siden.

Path og Query Parameters

Path parameter: En værdi som er en del af URL'ens path. Bruges fx til at identificere en bestemt resource. 

/animals/5

Her er 5 id'et på det animal vi vil hente.

app.get("/beers/:beerType/:amount", (req, res) => {
    console.log(req.params);
    res.send({
        data: `You ordered ${req.params.amount} of ${req.params.beerType}`
    });
});

Query parameter: Bruges til at sende ekstra information i URL'en. 

/animals?type=cat

Her sender vi type=cat som en query parameter.

app.get("/bars/forgottenItems", (req, res) => {
    console.log(req.query);
    res.send({ data: req.query });
});

Vi kan også have flere query parameters:

/animals?type=cat&age=3

? starter query string, mens & adskiller flere parameters.

7.3 Request Data i Express

req.params

Bruges til at hente værdier fra URL'ens path.

app.get("/beers/:beerType/:amount", (req, res) => {
    res.send({
        data: `You ordered ${req.params.amount} of ${req.params.beerType}`
    });
});

Hvis vi besøger:

/beers/ipa/3

Så er req.params.beerType = "ipa" og req.params.amount = "3".

req.query

Bruges til at hente query parameters fra URL'en.

app.get("/bars/forgottenItems", (req, res) => {
    res.send({ data: req.query });
});

Fx:

/bars/forgottenItems?item=phone&color=black

req.query indeholder værdierne item og color.

req.body

Bruges til at hente data som clienten sender i request body. Fx med POST. 

app.use(express.json());

app.post("/api/animals", (req, res) => {
    const newAnimal = req.body;
    res.send({ data: newAnimal });
});

express.json() gør det muligt at læse JSON fra request body gennem req.body. Det er middleware.

7.4 Fetch

Hvad er Fetch?

Fetch bruges til at sende HTTP requests og hente data fra en server eller et API.

Fetch er asynchronous, hvilket betyder at vi ikke får et resultat med det samme. Den returnerer et Promise.

GET Request med Fetch

GET henter data.

fetch("/api/animals")
    .then((response) => response.json())
    .then((result) => {
        console.log(result);
    });

.then(): Håndterer resultatet når det er færdigt.

response.json(): Læser JSON fra responsen og laver det om til JavaScript-data.

POST Request med Fetch

POST sender data til serveren. Fx for at oprette et dyr.

fetch("/api/animals", {
    method: "POST",
    headers: {
        "Content-Type": "application/json"
    },
    body: JSON.stringify({
        name: "Cat"
    })
});

method: Bestemmer at vi bruger POST.

headers: Fortæller serveren at det er JSON.

body: Indeholder data.

JSON.stringify(): Konverterer et JavaScript-object til en JSON-string.

Fetch i Node.js

Vi kan også bruge fetch direkte i Node.js på serversiden. Det har vi fx gjort i vores Planter-projekt (util/fetchPlants.js): 

let plants;

async function fetchPlants() {
    if (!plants) {
        const response = await fetch("https://www.plantsolve.com/api/v1/plants/index.json");
        plants = await response.json();
    }

    return plants;
}

Vi henter plantedata fra et eksternt API. Vi gemmer resultatet i plants, så vi ikke behøver hente data igen hver gang funktionen kaldes.

async/await

Async: Bruges til at lave en asynchronous funktion som returnerer et Promise.

Await: Venter på at et Promise bliver afgjort før funktionen fortsætter. Stopper ikke hele programmet. 

async function getAnimals() {
    const response = await fetch("/api/animals");
    const result = await response.json();

    console.log(result);
}

getAnimals();

Her venter vi først på responsen fra serveren og derefter på at JSON-data bliver læst.
