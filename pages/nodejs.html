3. Node.js & NPM

Node.js | NPM | package.json | Scripts | Nodemon

3.1 Node.js

Hvad er Node.js?

Med Node.js kan man køre JavaScript uden for browseren! Normalt køres JavaScript i browseren, altså client-side, men med Node.js kan vi også køre det på serveren, server-side.

Du kan fx lave API'er, scripts, automatisering og CLI.

Køre JavaScript med Node.js

Når vi vil køre en JavaScript-fil med Node, skriver vi i terminalen: 

node app.js

Kører filen app.js.

Node REPL

REPL står for Read, Evaluate, Print, Loop.

Det er et miljø hvor vi kan skrive JavaScript direkte i terminalen uden en fil.

Start REPL:

node

Derefter:

> 2 + 2
4

Afslut:

.exit

3.2 NPM

Hvad er NPM?

NPM (Node Package Manager) er en package manager til Node.js. Den bruges til at installere og administrere packages (biblioteker) som vi kan bruge i vores projekter, så vi ikke behøver at skrive alting fra bunden.

Vi bruger npm fordi den allerede følger med Node.js og er nem at bruge. Der findes andre package managers der grundlæggende kan det samme.

Installation af Packages

Vi kan bruge npm direkte i terminalen med npm install.

Fx Express:

npm install express

NPM tilføjer Express til dependencies i package.json.

Dependencies og DevDependencies

Dependencies: Packages som vores applikation har brug for når den kører. Fx Express.

DevDependencies: Packages som kun bruges under development, fx Nodemon. 

npm install express

Installerer Express som en dependency.

npm install --save-dev nodemon

Installerer Nodemon som en devDependency.

node_modules

node_modules er den mappe hvor NPM installerer projektets packages og dependencies.

Når vi installerer Express bliver det fx lagt i node_modules.

RULE: Vi må ikke pushe node_modules til GitHub, fordi mappen kan være meget stor og alligevel kan genskabes med npm install.

Derfor tilføjer vi node_modules/ til vores .gitignore.

3.3 package.json

Hvad er package.json?

package.json indeholder information om projektet. Bruges fx til at holde styr på dependencies, scripts og metadata.

Eksempel:

{
  "name": "my-project",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "start": "node app.js"
  },
  "dependencies": {
    "express": "^5.1.0"
  }
}

name: Projektets navn.

version: Projektets version.

type: Bestemmer hvilket modulsystem projektet bruger. module betyder ES Modules.

scripts: Kommandoer vi kan definere og køre i terminalen.

dependencies: Packages vi bruger i projektet.

npm init

Opretter package.json i et nyt projekt.

npm init

Herefter kan man svare på spørgsmål vedrørende projektet.

package-lock.json

package-lock.json bliver automatisk oprettet af NPM og holder styr på de præcise versioner af projektets installerede dependencies.

package.json: Dependencies og accepterede versioner.

package-lock.json: De konkrete versioner så de kan være ens på tværs af computere.

RULE: Vi skal normalt pushe både package.json og package-lock.json til GitHub, men ikke node_modules.

3.4 NPM Scripts

Hvad er Scripts?

I package.json kan vi definere scripts. Det er kommandoer som vi kan køre fra terminalen med NPM.

Det gør det nemmere at starte vores projekt uden at skulle skrive hele kommandoen hver gang.

Fx i package.json:

{
  "scripts": {
    "start": "node app.js",
    "dev": "nodemon app.js"
  }
}

npm run

Vi kan køre vores scripts fra terminalen.

npm start

Kører vores start-script som starter app.js med Node.js. 

npm run dev

Kører vores dev-script som starter app.js med Nodemon.

npm start er en genvej til npm run start.

3.5 Nodemon

Hvad er Nodemon?

Nodemon er et værktøj der automatisk genstarter når vi ændrer og gemmer kode.

I stedet for at vi skal stoppe og køre serveren igen når vi laver ændringer, gør Nodemon det for os.

Node: Kører vores JavaScript-kode. Vi skal selv genstarte efter ændringer.

Nodemon: Genstarter automatisk applikationen når filer ændres.

RULE: Nodemon bruges kun under development og ikke i production.
