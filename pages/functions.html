2.1 Functions

Hvad er en funktion?

Funktioner er den grundlæggende byggesten i JavaScript. En funktion indeholder kode der udfører en opgave eller udregning. Kan tage imod input og returnere et output. 

function addNumbers(a, b) {
    return a + b;
}

console.log(addNumbers(5, 10)); // 15

Den består af function keyword, funktionens navn, parametre i () og kode i {}.

a og b er parametre, 5 og 10 er arguments. Return returnerer summen af a + b.

Parameters, Arguments og Return

Parametre: Variabler defineret i funktionens parentes. Modtager værdier.

Arguments: De værdier vi sender med når vi kalder funktionen.

Return: Den værdi som funktionen returnerer. Derefter stopper funktionen.

2.2 Function Types

Function Declaration

Når der deklareres med function keyword og et navn, er det en function declaration. Bliver hoisted, så den kan kaldes før den er deklareret. Function addNumbers fra før er en function declaration.

Anonymous Function / Function Expression

En anonym funktion er en funktion uden navn. Hvis funktionen tildeles en variabel kaldes den en function expression. 

const addNumbers = function(a, b) {
    return a + b;
};

console.log(addNumbers(5, 10)); // 15

Funktionen gemmes i variablen addNumbers.

Arrow Function

Skriver => i stedet for function.

const addNumbers = (a, b) => {
    return a + b;
};

console.log(addNumbers(5, 10)); // 15

Kan også skrives endnu kortere.

const addNumbers = (a, b) => a + b;

2.3 Callbacks

Callback Functions

En funktion der sendes som argument til en anden funktion. Den anden funktion kan kalde callback-funktionen når der er behov for det.

Callback-funktion:

function genericActionPerformer(name, action) {
    return action(name);
}

Funktion der fungerer som action brugt i genericActionPerformer: 

function playingGuitarAction(name) {
    return `${name} likes to play guitar`;
}

Her sendes playingGuitarAction som argument til genericActionPerformer. 

console.log(genericActionPerformer("Elias", playingGuitarAction));

Andre callbacks

Callback functions kan også bruges som anonymous eller arrow functions.

Arrow function

const watchingMoviesAction = (name) => {
    return `${name} likes to watch movies`;
};

console.log(genericActionPerformer("Magnus", watchingMoviesAction));

Anonymous function

console.log(genericActionPerformer("Magnus", function(name) {
    return `${name} likes to watch movies`;
}));

One-liner

console.log(genericActionPerformer("Jacob", (name) => `${name} likes sailing`));

2.4 Loop Methods

Loop methods bruges til at arbejde med elementerne i et array.

forEach()

Bruges til at udføre noget for hvert element i et array. Returnerer ikke et nyt array, men undefined. 

const numbers = [1, 2, 3];

numbers.forEach((number) => {
    console.log(number);
});

// Printer 1, 2 og 3

map()

Kan bruges til at ændre elementerne i et array og returnere et nyt array med resultaterne. Returnerer en liste med samme størrelse 1:1. 

const numbers = [1, 2, 3];

const doubledNumbers = numbers.map((number) => {
    return number * 2;
});

console.log(doubledNumbers); // [2, 4, 6]

filter()

Bruges til at filtrere elementer ud fra en betingelse. Returnerer et nyt array med dem der opfylder betingelsen. 

const numbers = [1, 2, 3, 4, 5];

const filteredNumbers = numbers.filter((number) => {
    return number > 3;
});

console.log(filteredNumbers); // [4, 5]

find()

Finder det første element der opfylder en betingelse. Returnerer undefined hvis det ikke findes. 

const numbers = [1, 2, 3, 4, 5];

const foundNumber = numbers.find((number) => number > 3);

console.log(foundNumber); // 4

findIndex()

Finder index for det første element der opfylder en betingelse. Returnerer -1 hvis der ikke findes et match. 

const numbers = [1, 2, 3, 4, 5];

const index = numbers.findIndex((number) => number > 3);

console.log(index); // 3

reduce()

Bruges til at samle elementerne i et array til et resultat, fx summen af alle tallene. 

const numbers = [1, 2, 3, 4];

const sum = numbers.reduce((accumulator, number) => {
    return accumulator + number;
}, 0);

console.log(sum); // 10

Her er accumulator det samlede resultat indtil videre, number er det aktuelle element og 0 er startværdien.

for Loops vs. Loop Methods

Vi foretrækker loop methods i stedet for traditionelle for loops fordi de tydeligere viser hvad vi vil gøre med vores data. Vi vil gerne arbejde med funktioner og undgå side effects.

RULE 1: Brug altid loop methods i JavaScript.

RULE 2: Brug ikke for loops medmindre du skal fingertælle.

RULE 3: Brug .map() hvis du skal bruge et nyt array med resultaterne. Brug .forEach() hvis du bare skal udføre noget for hvert element.

2.5 Side Effects

Hvad er Side Effects?

Side effects sker når en funktion påvirker noget uden for sig selv. Fx hvis den ændrer på noget eksisterende i koden. Vi vil helst undgå side effects når vi bruger loop methods.

Mutation af Objects og Arrays

Mutation betyder at vi ændrer på eksisterende data. Fx hvis vi bruger .map() til at ændre et object direkte, ændrer vi også det oprindelige object. 

const countries = [
    { name: "Denmark", gdp: 100 },
    { name: "Lesotho", gdp: 50 }
];

const updatedCountries = countries.map((country) => {
    if (country.name === "Lesotho") {
        country.gdp += 500;
    }
    return country;
});

console.log(countries[1].gdp); // 550

Det oprindelige object blev ændret fordi country refererer til det samme object som i countries.

Hvordan undgår vi Side Effects?

Vi bruger spread syntax (...) for at oprette et nyt object i stedet for at ændre på det allerede eksisterende. 

const updatedCountries = countries.map((country) => {
    if (country.name === "Lesotho") {
        return { ...country, gdp: country.gdp + 500 };
    }
    return country;
});

RULE: Undgå at ændre på de oprindelige objects når du bruger .map() til at ændre data.
