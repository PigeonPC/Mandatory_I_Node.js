5. Express & Servers

Client-server | Express | Routes | Middleware

5.1 Client-Server Model

Hvad er Client-Server?

Client-server modellen beskriver hvordan en client og server kommunikerer med hinanden.

Client: Den der sender en request til serveren. Fx en browser.

Server: Modtager en request fra clienten, behandler den og sender en HTTP response tilbage.

Fx når vi åbner en hjemmeside i browseren, sender browseren en GET request til serveren for at hente indholdet.

5.2 Express

Hvad er Express?

Express er et framework til Node.js som vi bruger til at lave servere og API'er.

Det gør det nemmere at arbejde med HTTP requests og responses og oprette routes til vores endpoints.

Vi installerer Express med NPM:

npm install express

Opsætning af en Express-server

Eksempel med CommonJS og error handling i app.listen(): 

const express = require("express");
const app = express();

app.get("/", (req, res) => {
    res.send("Hello World!");
});

const PORT = 8080;

app.listen(PORT, (error) => {
    if (error) {
        console.log(error);
        return;
    }

    console.log("Server is running on port", PORT);
});

require("express"): Importerer Express.

express(): Opretter en Express-app.

app.get(): Definerer en route til GET requests.

res.send(): Sender en response tilbage til clienten.

app.listen(): Starter serveren på en bestemt port.

Vi kan også starte serveren sådan her:

app.listen(8080, () => {
    console.log("Server is running on port 8080");
});

Starter serveren på port 8080. Vi kan se den på: http://localhost:8080

5.3 Routes

Hvad er en Route?

En route bestemmer hvordan serveren reagerer på en HTTP request. Vi opretter routes med fx app.get() og app.post().

En route består af en HTTP method, en URL path og en callback function der håndterer requesten.

app.get()

Håndterer GET requests når en client vil hente data fra serveren. 

app.get("/api/animals", (req, res) => {
    res.send({ data: animals });
});

Serveren sender animals-arrayet tilbage til clienten når clienten laver en GET request på /api/animals.

res.send() og res.sendFile()

res.send(): Bruges til at sende data tilbage til clienten. res = response. Sender fx tekst, HTML eller et JavaScript-object. 

app.get("/", (req, res) => {
    res.send("Hello World!");
});

res.sendFile(): Sender en fil tilbage til clienten. Fx en HTML-fil. 

app.get("/", (req, res) => {
    res.sendFile(__dirname + "/index.html");
});

index.html bliver sendt når clienten besøger /.

__dirname: Indeholder stien til mappen hvor den aktuelle JavaScript-fil ligger. Det er smart når flere arbejder på projektet og har forskellige stier på deres computere.

5.4 Middleware

Hvad er Middleware?

Middleware er funktioner som Express bruger til at behandle requests. De har adgang til req og res og kan fx læse JSON-data fra en request.

app.use()

Tilføjer middleware i Express:

app.use(express.json());

express.json()

Bruges til at læse JSON fra en HTTP request body så data bliver tilgængelige gennem req.body. 

const express = require("express");
const app = express();

app.use(express.json());

app.post("/api/animals", (req, res) => {
    console.log(req.body);
    res.send({ data: req.body });
});

Clienten kan sende JSON-data med POST. Express kan læse dataene og bruge dem gennem req.body.
